Lottie Animation Files — Required JSON Files
=============================================

Place the following Lottie JSON animation files in this res/raw/ directory.
You can download free Lottie animations from https://lottiefiles.com

Required files:
  - anim_loading_dots.json       (dots loading / typing indicator)
  - anim_ai_sparkle.json         (AI sparkle / magic effect)
  - anim_ai_avatar.json          (AI assistant avatar animation)
  - anim_typing_dots.json        (three dots typing indicator)
  - anim_qr_scan.json            (QR scan line animation)
  - anim_success_check.json      (green checkmark success)
  - anim_crown.json              (gold crown for leaderboard #1)
  - anim_onboarding_books.json   (books animation for onboarding page 1)
  - anim_onboarding_ai.json      (AI brain/sparkle for onboarding page 2)
  - anim_onboarding_trophy.json  (trophy for onboarding page 3)

  - "typing dots" for anim_typing_dots

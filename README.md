# Namma-Pustaka
AI-Powered Smart Rural Library Assistant

## Overview
Namma-Pustaka is a digital library management platform built for rural schools to modernize traditional libraries and encourage reading culture using AI-powered recommendations and smart book management.

---

## Features

### Student Features
- Browse books
- AI-generated summaries
- QR code borrowing system
- Book reviews & ratings
- Reading leaderboard

### Teacher Features
- Manage book inventory
- Track borrowed books
- Overdue reminders
- Reading analytics

### AI Features
- AI librarian chatbot
- Smart recommendations
- Voice search
- Kannada book summaries

---

## Installation
1. Clone repository
2. Open in Android Studio
3. Configure Firebase
4. Add `google-services.json`
5. Sync Gradle
6. Run app
